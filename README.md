# naminami

X波・Y波を1モータずつで駆動し、正転・逆転・停止の組み合わせで全方向移動する機構のシミュレーション。

- `index.html` — シミュレータ。**理想モード**（連続な波の高さ合成）と**実機近似モード**（実際に作れる機構）を切り替えられます。
- `sim3d.html` — 実機（案A）の3Dビューア。レールの円運動、市松配置、層構造を回して見られます。依存ライブラリなし。
- `sim3d-vehicle.html` — 機構を裏返して地面を走らせた場合のシミュレータ。全列が接地するので卓上とは挙動が変わります。
- `docs/hardware-approximation.md` — 実機化の設計メモ。理想モデルが現実で壊れる4点と、その回避策・寸法・部品表・製作手順。
