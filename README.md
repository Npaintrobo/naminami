# naminami

X波・Y波を1モータずつで駆動し、正転・逆転・停止の組み合わせで全方向移動する機構のシミュレーション。

**すべてシミュレーション結果です。実機の測定値は1つもありません。**
摩擦係数 μ・パッドの沈み込み δp・実際の接地窓は未測定で、結論はこれらの仮定値に依存します。

## シミュレータ

- `index.html` — **理想モード**（連続な波の高さ合成）と**実機近似モード**（実際に作れる機構）を切り替えられます。
  実機近似モードの接触は正則化クーロン摩擦で、μ と δp を振れます。
- `sim3d.html` — 実機（案A）の3Dビューア。レールの円運動、市松配置、層構造を回して見られます。依存ライブラリなし。
- `sim3d-polar.html` — **和差位相式・偏極操舵**の3Dシミュレータ。2軸を直接回して、その和が波を進め
  差が推力方向を回すのを見られます。逆旋回2偏心のアームを接触子ごとに描画。上下・ピッチ・ロールつき。
- `sim3d-vehicle.html` — 機構を裏返して地面を走らせた場合のシミュレータ。荷重分担 / 時間交替 / 傾斜円盤の3方式を比較できます。

## ベンチ（`node bench/*.mjs`）

ブラウザを使うベンチ（`polar3d.mjs`, `table.mjs`）は `npm install` のあと
`npx playwright install chromium` が要ります。別の場所の Chromium を使うときは
`CHROMIUM_PATH=/path/to/chrome node bench/polar3d.mjs`。

- `compare.mjs`, `run.mjs` — 4方式を同じ物理コアで比べる。未測定パラメータを振っても順位が入れ替わらないことを確認。
- `phasestep.mjs` — **操舵誤差を決めているのは位相ステップ Δφ** であることの確認。Δφ=60° で 3.3°、15° で 46.9°。
  荷速は Δφ でほとんど変わらないので、粗くするのはタダ。ただし波長が短くなり、運べる荷が小さくなる。
- `spatial.mjs` — 足に空間座標を持たせた6自由度モデルで「これは波動か」を判定する。
  **車両では位相配置は当番表にすぎません。** ケースB（卓上）の結論は後の検証で崩れたので
  採用しないでください（ファイル冒頭に注記あり）。
- `foot.mjs` — 傾斜円盤の足1本を単体機構として見たときの寸法決め。掃引体積の外形は傾きに依らず R なので、ピッチ下限は 2R。
- `table.mjs` — `index.html` の実機近似モードを Playwright でヘッドレス実行し、搬送速度と操舵の線形性を測る。
  `npm install playwright` が要ります。
- `polar.mjs` — **数値の出どころ。** 和差位相式・偏極操舵を案Aと同じ6自由度コアで検証する。
  静的釣合いから開始し回転数をランプする。接地剛性は δp から二分法で整定。
  接触が切れない条件（位相ギャップ）と姿勢を保持できる条件（支持多角形の余裕）を分けて出す。
- `polar3d.mjs` — `sim3d-polar.html` の一致検査。3D可視化が物理と食い違っていないかを見るだけで、
  **数値は `polar.mjs` が正**（3Dはヨーを持たない）。`npm install` が要ります。
- `membrane.mjs` — **上下だけの進行波を厚いゴム膜に通すと推力が出るか。** 剛体の歯は 0 mm/s、
  膜を挟むと滑り 0〜2% で走る。面内駆動の機構が一切要らなくなる。
- `mechanism.mjs` — 機構として何なのか。足先軌道が案Aのオービタルレールと同一であること、
  2モータで自由度が閉じること、実現2通りの部品数、非ホロノミック性、ヨーの作り方を検証。
- `wavetest.mjs` — **⚠ 無効**。足の空間座標がなく、位相の並べ替え不変性は数式上の恒等式でした。
  なぜ無効だったかの記録として残してあります。後継は `spatial.mjs`。

## いまの結論

探索は2本に分かれています。**どちらも実機で測っていません。**

### 1. 直交2ラティス（案A） — 元の路線の到達点

卓上コンベアとしては成立しますが、あとから出てきた寸法制約が厳しい。

```
荷の差し渡し  ≪  λ = (360/Δφ)·p  ≤  6·p          （Δφ ≥ 60° が操舵の要求）
```

ピッチ 50mm なら荷は 100mm 級まで。**車体サイズの荷は原理的に載らないので、車両には使えません。**
停止軸のリトラクトは必須で、省くと荷速が r·ω の 1% まで落ちます。

### 2. 和差位相式・偏極操舵 — 案Aの制約を外す候補

搬送位相 `q=(φA+φB)/2` と偏極位相 `ψ=(φA−φB)/2` を分けることで、案Aの過拘束が
**構造的に消えます**。差動で追い込んでから両軸を揃える制御で、任意の固定方位を保持できます。

**機構としては「案Aのオービタルレールの、軌道面を steer できる版」です**（足先軌道は数値的に同一）。
足1個は1自由度、ψ は全足共通なので全体で2自由度、2モータで過不足なく閉じます。
ただし **厳密には非ホロノミック**（ユニサイクルと同型）で、ヨーは2モータでは動かせません。

優位は**操舵誤差ではなく、速度の一様性と滑り**にあります。

| | 案A | 偏極操舵 |
|---|---|---|
| 速度の方向依存 | 89〜178 mm/s（2倍） | **185 mm/s 一定** |
| 直進性 | 斜めで弦89/経路120（蛇行） | 弦 = 経路 |
| 滑り | 5.6〜29.4% | **0.6%** |
| 操舵誤差 | 0.94° | 0.51°（うち0.5°は制御の不感帯） |
| 停止軸のリトラクト | 必須 | 不要 |

案Aの `荷 ≪ λ ≤ 6·p` という制約は過拘束から来ていたので、こちらでは外れます
（ただしその制約の根拠だった卓上試験自体が未確立です。下記）。
**ただし b=6mm では両方式とも周期的に完全離床します**（荷重リップル 110%前後）。
b を 1.5mm に下げると 13% まで収まり、推力は `a·q̇` で決まるので速度は落ちません。

**ただし和差位相分解も、位相制御による任意方向の摩擦搬送も既知です**
（WO2013/134388A1、US8390218B2、US5770913A、US9038815B2、US2018/0217662A1）。
残り得る新規性は「空間位相付き多数接触子＋独立上下カム＋逆回転偏心対＋差動伝達」という
**伝達構成の具体**に限られ、差動歯車・バックラッシュ・位相保持トルクはまだ一切モデル化していません。
**卓上（有限の荷）については何も立っていません。** 位相原点を走査すると、空間波にも
シャッフルにも一貫した優位が出ません。

傾斜円盤方式は速度を解決しますが、Disney の HoloTile（US 2018/0217662 A1、優先日 2017-01-30）と
機構レベルで同じで、しかも上下動が必須なぶん車輪配列より劣ります。研究の本線からは降ろしました。
