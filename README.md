# naminami

X波・Y波を1モータずつで駆動し、正転・逆転・停止の組み合わせで全方向移動する機構のシミュレーション。

- `index.html` — シミュレータ。**理想モード**（連続な波の高さ合成）と**実機近似モード**（実際に作れる機構）を切り替えられます。
- `sim3d.html` — 実機（案A）の3Dビューア。レールの円運動、市松配置、層構造を回して見られます。依存ライブラリなし。
- `sim3d-vehicle.html` — 機構を裏返して地面を走らせた場合のシミュレータ。荷重分担 / 時間交替 / 傾斜円盤の3方式を切り替えて比較できます。
- `bench/compare.mjs`, `bench/run.mjs` — 4方式を同じ物理コアで比べるベンチマーク。未測定パラメータを振っても順位が入れ替わらないことを確認しています。
- `bench/foot.mjs` — 傾斜円盤の足1本を単体機構として見たときの寸法決め。
- `bench/wavetest.mjs` — 位相の空間配置を壊しても性能が変わらないことの確認。傾斜円盤式はもう波動機構ではありません。
- `docs/design-history.md` — 設計がどこで何度ひっくり返ったかの記録。結論だけでなく覆された理由を残しています。
- `docs/hardware-approximation.md` — 実機化の設計メモ。理想モデルが現実で壊れる4点と、その回避策・寸法・部品表・製作手順。
