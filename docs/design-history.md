# 設計の変遷 — 何がどこでひっくり返ったか

`docs/hardware-approximation.md` は**案A（直交2ラティス）前提で書かれていて、いまの理解とは合いません**。
このメモはその後に分かったことの記録です。結論だけの文書より、覆された理由が残っている文書のほうが後で効くので、
順番と、それぞれで測った値をそのまま残します。

**結論を先に**: 局所的な改良を積み上げた結果、着地点は「劣化した車輪配列」になりました。
機構が機構のままでいられた最後の点は **案A（卓上）** です。

---

## 0. 出発点 — 案A 直交インターリーブ・オービタルレール

`index.html` の理想波を実機に落としたもの。X波とY波を1モータずつ、位相をずらした偏心で作り、
歯を市松に並べて干渉を避ける。詳細は `hardware-approximation.md`。

**卓上（小さい荷が数列にだけ乗る）ではこれで成立しています。** 操舵誤差 3.7%、接地圧 8 kPa、
連続ゴム皮膜で密封可能、真の進行波駆動。この結論は最後まで生き残りました。

---

## 1. 過拘束の発見 — 荷重分担では操舵が壊れる

**Xの足は「vx = r·ωx かつ vz = 0」を、Yの足は「vz = r·ωy かつ vx = 0」を要求します。過拘束です。**
どちらかが必ず滑り、しかもクーロン摩擦は滑り速度に依存しないので、**遅いほうがフルの摩擦力で
ブレーキとして効きます**。

卓上は荷が動くと接地列が入れ替わって偏りが均されるので問題になりません。
**全面接地（＝車両）にすると偏りが系統的に残って壊れます。**

| | 最大操舵誤差 |
|---|---|
| 卓上・荷重分担（荷が3列だけ接地） | 3.7° |
| 車両・荷重分担（全列が接地） | **65.1°** |
| 車両・時間交替 8Hz | 0.0° |

### ここで訂正したこと

- **`η = 0.55` は根拠のない仮定値でした。** 推力を `η·r·ω·(荷重分担)` と置いていたのが誤りで、
  「荷重を持っていない側も同時に接地してブレーキになる」ことが入っていませんでした。
  クーロン摩擦の力の釣り合いで解き直しました。
- 一度「車両版は全面接地なので操舵誤差 0.0°」と記録しましたが**逆でした**。全面接地こそが壊れます。
- 静的な釣り合いで解いた操舵の表（1:0.5 → 51.9° など）は**縮退した方程式を収束不足で解いた値**でした。
  両ラティス同荷重だと解が一意に決まりません。荷重リップルで縮退が解けるので動的に積分する必要があります。

---

## 2. 時間交替 — 過拘束は消えるが、周波数に上限がある

XとYを数Hzで交互に持ち上げ、接地するラティスを常に1つに保つと過拘束が消えます。
リトラクト機構をそのまま流用できます。

**ただし上限があります。** 1つの窓のあいだに機体が `r·ω` まで加速しきれないと、
結局2つの要求が平均されて荷重分担と同じ歪みが出ます。

```
μg·(T/2) ≥ r·ω    →    f ≤ μg / (2·r·ω)
```

実機プリセット（1500mm / r19 / 900rpm）で上限 1.6 Hz。実測でも 1.5 Hz まで誤差 2° 以内、
2 Hz で 15°、8 Hz で 32° と理論どおりに崩れました。

低い交替周波数は前後の脈動を大きくするので、速い機体ほど両立が難しくなります。

---

## 3. 滑りの定量化 — 直交2ラティスは常時 71% 滑っている

「指令ベクトルを各足に投影しているのではなく、2つの拘束を競合させて摩擦の釣り合いで決めている」
という指摘を受けて測りました。45°方向へ走らせたとき：

| 方式 | 速度 | 滑り率 |
|---|---|---|
| 直交2ラティス 同時接地 | 0.707·rω | **71%** |
| 交替 8Hz | 0.707·rω | 52% |
| 交替 3Hz | 0.707·rω | 20% |
| 1ラティス旋回 | **1.000·rω** | **0%** |

**直進でも 71% 払っています。** 厳密な機構ではありませんでした。

---

## 4. 1ラティス旋回 — 厳密だが非ホロノミック

ラティスを1つに減らしてモジュールごと指令方向へ旋回させると、`|v| = r·ω`、`∠v = ψ` という
極座標そのものになります。滑り 0%、速度 √2 倍、部品はむしろ半分、市松も層構造も不要。

**ただし瞬時の速度が現在の旋回角の方向に拘束されるので、非ホロノミックです。**

---

## 5. オフセットキャスタ — ホロノミックになるが、面接地では高くつく

旋回軸から距離 `d` だけ接地パッチをずらすと、旋回速度 ψ̇ が横速度 `d·ψ̇` を生みます。
`(ω, ψ̇)` で平面を張れるので瞬時に任意方向へ出られます（パワードキャスタの既知の結果）。

**ただし車輪と違って接地が面なので、パッチを回すと全面がスクラブします。**

```
滑り / (r·ω)  =  (2/3) · (ρ/d) · (v横 / r·ω)      ρ = パッチ半径
```

`d = ρ` なら横速度 0.5·rω で滑り 33%。**直進時は 0%** なので「曲がるときだけ払う税」になり、
常時 71% よりは明確に上です。ヨーを得るにはモジュール2基（4入力3自由度）。

---

## 6. 傾斜円盤 — 速度は解決するが、機構の存在理由を失う

先端を傾けた円盤にすると、最下点はピン軸から `e = R·cosα` ずれた方位 χ にあり、深さ `R·sinα` は
χ に依りません。ピンの自転をクランクに 1:1 同期させ位相差 δ でずらすと、接地の瞬間の掃引方向が
δ だけで決まります。全ての足で同じベクトルなのでスクラブが出ません。

さらに**速度とストロークが分離します**。`v = e·ω` で、クランク `r` は接地クリアランスだけで決めてよい。

| 目標 1000 mm/s | 必要な r | ストローク | 振動 | 皮膜ひずみ |
|---|---|---|---|---|
| 直交2ラティス | 64 mm | 129 mm | 16 G | 27% |
| 1ラティス旋回 | 32 mm | 64 mm | 8 G | 14% |
| **傾斜円盤** | **6 mm** | **12 mm** | **1.5 G** | **2.5%** |

ピン軸自体を β だけ傾けて自転させれば、法線の歳差で上下も掃引も1回転から出ます（`bench/foot.mjs`）。
運動が1つで済み、`α=30°, β=25°` でストローク 22mm・815 mm/s・滑り 7%。

### そして、ここで機構ではなくなりました

**(a) 波動ではない。** 位相の空間配置を壊しても性能が変わりません（`bench/wavetest.mjs`）。

| 位相の配り方 | 速度 | 方向 | 滑り |
|---|---|---|---|
| 進行波・1波長 | 783 mm/s | 134.7° | 12% |
| **線形位相をシャッフル** | **783 mm/s** | **134.7°** | **12%** |
| 完全ランダム | 781 mm/s | 133.8° | 15% |
| 全部同位相 | 0 mm/s | — | 97% |

小数点以下まで一致します。位置は一切効いていない。位相差は波ではなく
**「常にどれかが接地している」ための当番表**でしかありません。各足が自前で推力を出すので、
波が荷を運ぶ役目を失いました。

**(b) 歩容でもない。車輪である。しかも車輪より悪い。**

決定的なのは**どの軸で駆動するか**でした。

| | 駆動軸 | 推力の向き | 上下動 |
|---|---|---|---|
| 車輪 | 円盤自身の法線まわり | 一定 | **不要** |
| この円盤 | 鉛直軸まわり | 1回転で360°回る | **必須** |

円盤を軸に剛結して鉛直まわりに引きずっているので、掃引方向が θ とともに回ります。
だから「向きが合っている間だけ接地させる」ために上下動が要る。
**上下機構は、自分で作り出した問題を自分で塞いでいるだけでした。**

| | 車輪配列 | 傾斜円盤配列 |
|---|---|---|
| 接地率 | 100% | 12% |
| 滑り | ほぼ 0（転がり） | 7〜12% |
| 接地応力 | 基準 | 約8倍 ＋ リムの点接触 |
| 上下機構・位相配り | 不要 | 必須 |

**(c) 先行例がある。** Disney の HoloTile floor（Lanny Smoot, 2024）が
「回転しピボットするディスクの縁を接地させ、その角度方位で進行方向を決める」もので、機構レベルで同じです。
以前「マクロ機械式 × 全方向 × 位相操舵の先行例は見つからなかった」と記録しましたが**誤りでした**。
検索語が波動・進行波に寄っていて当たっていませんでした。しかも HoloTile の「spin and pivot」は
自軸駆動＋操舵、つまり**車輪の正しい使い方**です。

---

## 何を失ったか

| | 連続ゴム皮膜 | 接地面積 | 真の進行波 | アクチュエータ |
|---|---|---|---|---|
| 案A（卓上） | ✓ | ✓ 8 kPa | ✓ | 2 |
| 時間交替 | ✓ | ✓ | ✓ | 2＋交替 |
| 1ラティス旋回 | ✓ | ✓ | ✓ | 2 |
| オフセットキャスタ | △ | ✓ | ✓ | 4 |
| **傾斜円盤** | **✗** | **✗ 点接触** | **✗** | 2 |

**円盤に行った1手で、この機構を他と区別していた性質を全部捨てました。**
対価は「速度」で、その速度が要るのは**車両にした場合だけ**でした。

間違いは2箇所です。

1. **車両にしたこと。** 速度の制約が生まれたのはここから。卓上のままなら 50 mm/s で問題なかった
2. **速度のために円盤に行ったこと。** ここで波・皮膜・接地圧を全部失った

## いまの立ち位置

**戻るなら案Aです。** 卓上コンベアとして操舵誤差 3.7%、進行波駆動、密封可能、接地圧 8 kPa。
`hardware-approximation.md` の卓上向けの結論（リトラクト必須、Stage 0 で η を実測、蛇腹皮膜）は
すべて生きています。今日から Stage 1 に行けます。

車両として使う場合は、`hardware-approximation.md` の内容は不十分です。
最低限、上の 1〜3 の内容（過拘束、交替の周波数上限、常時 71% の滑り）を読んでから設計してください。

## 未検証のまま残っていること

**すべて準静的クーロンモデルの中の話です。** `μ`、パッドの沈み込み `δp`、実際の接地窓は
一度も測っていません。滑りが 8% か 27% かは `δp` だけで決まり、交替周波数の上限は `μ` だけで決まります。

この会話でアーキテクチャは5回ひっくり返り、その全部がモデルの中の発見でした。
**次のラウンドもたぶんまたひっくり返ります。** 足1本のベンチ実測が先です。
