# 設計の変遷 — 何がどこでひっくり返ったか

`docs/hardware-approximation.md` は**案A（直交2ラティス）前提で書かれていて、いまの理解とは合いません**。
このメモはその後に分かったことの記録です。結論だけの文書より、覆された理由が残っている文書のほうが後で効くので、
順番と、それぞれで測った値をそのまま残します。

**この文書の数値はすべて「シミュレーション結果」です。実機の測定値は1つもありません。**
μ・パッドの沈み込み δp・実際の接地窓は一度も測っていません。以下で「測った」と書いてあるのは
すべてモデルの中の話です（以前この文書は同じものを「実測」と書いていました。誤りでした）。

**結論を先に**: 局所的な改良を積み上げた結果、着地点は「劣化した車輪配列」になりました。
機構が機構のままでいられた最後の点は **案A（卓上）** です。ただし案Aにも
**荷の差し渡し ≪ λ ≤ 6·ピッチ** という、あとから出てきた厳しい寸法制約があります（§1）。

再現手順は各節に置いてあります。すべて `node bench/*.mjs` で走ります。

## 0. 出発点 — 案A 直交インターリーブ・オービタルレール

`index.html` の理想波を実機に落としたもの。X波とY波を1モータずつ、位相をずらした偏心で作り、
歯を市松に並べて干渉を避ける。詳細は `hardware-approximation.md`。

卓上（小さい荷が数列にだけ乗る）ではこれで成立します。連続ゴム皮膜で密封可能、真の進行波駆動。
**この結論は最後まで生き残りましたが、成立条件は当初思っていたより狭いことが後で分かりました。**

## 1. 過拘束 — ただし「卓上か車両か」ではなく Δφ で決まる

**Xの足は「vx = r·ωx かつ vz = 0」を、Yの足は「vz = r·ωy かつ vx = 0」を要求します。過拘束です。**
どちらかが必ず滑り、しかもクーロン摩擦は滑り速度に依存しないので、**遅いほうがフルの摩擦力で
ブレーキとして効きます**。結果として進行方向が 45° 方向へ引き寄せられます。

**ただし、この過拘束が実際に害になるのは両ラティスの歯が「同時に」荷重を持っているときだけです。**
同時に接地する歯数は位相ステップ Δφ と接地窓で決まります。

```
同時接地歯数 ≒ 接地窓の角度幅 / Δφ        接地窓 = 2·acos(1 − δp/r)
```

`node bench/phasestep.mjs`（r=6mm, δp=0.3mm, μ=0.6, 300rpm, 全レール接地）:

| Δφ | 波長 λ | 同時接地歯数 | 最大操舵誤差 | 45°方向の荷速 |
|---|---|---|---|---|
| 120° | 3·p | 0.30 | 4.7° | 41% of rω |
| 90° | 4·p | 0.40 | 3.9° | 45% |
| **60°** | **6·p** | **0.61** | **3.3°** | **48%** |
| 45° | 8·p | 0.81 | 19.5° | 49% |
| 30° | 12·p | 1.21 | 37.9° | 49% |
| 15° | 24·p | 2.43 | 46.9° | 49% |

**Δφ を粗くすると誤差が一桁下がるのに、荷速はほとんど変わりません。** 操舵の改善はタダです。

### ここで訂正したこと（重要）

**「卓上（荷が3列だけ接地）なら 3.7°、車両（全列接地）なら 65.1°」と書いていたのは誤りでした。**
差を作っていたのは接地の局所性ではなく、2つの表が別のプリセットだったことです
（卓上側が Δφ=60°、車両側が Δφ=15°）。上の表のとおり、**全面接地でも Δφ=60° なら 3.3° です**。
接地が局所的かどうかは操舵誤差をほとんど動かしません。

- **`η = 0.55` は根拠のない仮定値でした。** 推力を `η·r·ω·(荷重分担)` と置いていたのが誤りで、
  「荷重を持っていない側も同時に接地してブレーキになる」ことが入っていませんでした。
  クーロン摩擦の力の釣り合いで解き直しました。`hardware-approximation.md` §3 の該当箇所も
  撤回済みに書き換えてあります。`index.html` の実機近似モードも η を廃してクーロン摩擦に差し替えました。
- 一度「車両版は全面接地なので操舵誤差 0.0°」と記録しましたが**逆でした**。さらにその後、
  上のとおり**全面接地かどうかがそもそも主因ではありませんでした**。
- 静的な釣り合いで解いた操舵の表（1:0.5 → 51.9° など）は**縮退した方程式を収束不足で解いた値**でした。
  両ラティス同荷重だと解が一意に決まりません。荷重リップルで縮退が解けるので動的に積分する必要があります。

### そして、これが案Aの寸法制約になります

操舵は Δφ を粗くしたい。しかし `λ = (360/Δφ)·p` なので、**Δφ ≥ 60° は λ ≤ 6·p を意味します**。
一方 §6 の空間モデルが示すとおり、有限寸法の荷を支え続けるには波長が荷より十分長いことが要ります。

```
荷の差し渡し  ≪  λ = (360/Δφ)·p  ≤  6·p
```

ピッチ 50mm なら λ ≤ 300mm、支えられる荷はせいぜい 100mm 級。
600mm の車体は λ の 2 倍あり、この不等式を満たしようがありません。
**直交2ラティスが卓上で成立して車両で壊れる本当の理由はこれです。**

## 2. 時間交替 — 過拘束は消えるが、周波数に上限がある

XとYを数Hzで交互に持ち上げ、接地するラティスを常に1つに保つと過拘束が消えます。
リトラクト機構をそのまま流用できます。

**ただし上限があります。** 1つの窓のあいだに機体が `r·ω` まで加速しきれないと、
結局2つの要求が平均されて荷重分担と同じ歪みが出ます。

```
μg·(T/2) ≥ r·ω    →    f ≤ μg / (2·r·ω)
```

`node bench/compare.mjs` 経由で `altXY` の操舵誤差を測ると、この上限が実際に効いています。

| 交替周波数 | demo機（600mm / r6 / 300rpm）<br>上限 15.6 Hz | 実機（1500mm / r19 / 900rpm）<br>上限 **1.64 Hz** |
|---|---|---|
| 0.5 Hz | 0.2° | 0.0° |
| 1.5 Hz | 0.1° | 0.0° |
| 2 Hz | 0.1° | **8.6°** |
| 3 Hz | 0.1° | 22.5° |
| 8 Hz | 0.1° | 40.4° |
| 交替なし（荷重分担） | 3.3° | 56.2° |

**予測どおり、崩れ始めるのがちょうど 1.64 Hz です。** モデルの中では、この式は当たっています。

### ここで訂正したこと

以前この文書には「車両・時間交替 8Hz → 0.0°」と「8 Hz で 32°」が両方載っていて矛盾していました。
**別のプリセットの値を条件を書かずに並べていたためです。** 上限が 15.6 Hz の機体と 1.64 Hz の機体では、
8 Hz は「余裕」と「大幅超過」の両方になります。以後、表には必ず機体条件を付けます。

低い交替周波数は前後の脈動を大きくするので、速い機体ほど両立が難しくなります。

## 3. 滑りの定量化

45°方向へ走らせたときの滑り率。**demo機（Δφ=60°, r=6mm, 300rpm, μ=0.6, δp=0.3mm）** です。

| 方式 | 速度 | 滑り率 |
|---|---|---|
| 直交2ラティス 同時接地 | 0.476·rω | 48% |
| 交替 8Hz | 0.477·rω | 24% |
| 交替 3Hz | 0.477·rω | 9% |
| 交替 1.5Hz | 0.477·rω | 5% |
| **1ラティス旋回** | **0.954·rω** | **1%** |

実機プリセット（Δφ=15°, r=19mm, 900rpm）では交替が効かず、8Hz でも 1.5Hz でも 45〜50% のままです。
上限 1.64 Hz を超えているからです。

**直進でも約半分を滑りに払っています。** 厳密な機構ではありませんでした。

> 以前ここには「71%」「0.707·rω」と書いてありましたが、現在のコードでは再現しません。
> 条件を書き残していなかったので、どのプリセットの値だったのか追跡できません。
> 上の表は条件付きで測り直したものです。

## 4. 1ラティス旋回 — 厳密だが非ホロノミック

ラティスを1つに減らしてモジュールごと指令方向へ旋回させると、`|v| = r·ω`、`∠v = ψ` という
極座標そのものになります。滑り 1%、速度 2倍、部品はむしろ半分、市松も層構造も不要。

**ただし瞬時の速度が現在の旋回角の方向に拘束されるので、非ホロノミックです。**

---

## 5. オフセットキャスタ — ホロノミックになるが、面接地では高くつく

旋回軸から距離 `d` だけ接地パッチをずらすと、旋回速度 ψ̇ が横速度 `d·ψ̇` を生みます。
`(ω, ψ̇)` で平面を張れるので瞬時に任意方向へ出られます（パワードキャスタの既知の結果）。

**ただし車輪と違って接地が面なので、パッチを回すと全面がスクラブします。**

```
滑り / (r·ω)  =  (2/3) · (ρ/d) · (v横 / r·ω)      ρ = パッチ半径
```

`d = ρ` なら横速度 0.5·rω で滑り 33%。**直進時は 0%** なので「曲がるときだけ払う税」になります。
ヨーを得るにはモジュール2基（4入力3自由度）。

## 6. 傾斜円盤 — 速度は解決するが、機構の存在理由を失う

先端を傾けた円盤にすると、最下点はピン軸から `e = R·cosα` ずれた方位 χ にあり、深さ `R·sinα` は
χ に依りません。ピンの自転をクランクに 1:1 同期させ位相差 δ でずらすと、接地の瞬間の掃引方向が
δ だけで決まります。全ての足で同じベクトルなのでスクラブが出ません。

さらに**速度とストロークが分離します**。`v = e·ω` で、クランク `r` は接地クリアランスだけで決めてよい。

| 目標 1000 mm/s | 必要な r | ストローク | 振動 | 皮膜ひずみ |
|---|---|---|---|---|
| 直交2ラティス | 64 mm | 129 mm | 16 G | 27% |
| 1ラティス旋回 | 32 mm | 64 mm | 8 G | 14% |
| **傾斜円盤** | **6 mm** | **12 mm** | **1.5 G** | **2.5%** |

ピン軸自体を β だけ傾けて自転させれば、法線の歳差で上下も掃引も1回転から出ます（`node bench/foot.mjs`）。
運動が1つで済み、`α=30°, β=25°` でストローク 22mm・815 mm/s・滑り 7%。

### (a) 波動か — 荷の寸法で答えが変わる

`node bench/spatial.mjs`。足に (x, z) 座標を与え、剛体を6自由度（並進3・ヨー・ピッチ・ロール）で
積分します。位相の空間配置は「法線力 → 姿勢 → 接地分布 → モーメント」の閉ループを通してのみ効きます。

**ケースA 車両（12×12足が大きな剛体の下に全部入る）**

| 位相の配り方 | 速度 | 方向 | 上下振動 | 傾き | 最小接地 | 無接地 |
|---|---|---|---|---|---|---|
| 波・x方向 1波長 | 748 | −127.7° | 1.34 G | 1.437° | 0 | 10.8% |
| 波・斜め45° 1波長 | 782 | −131.9° | 0.18 G | 0.006° | 12 | 0.0% |
| **同じ位相集合を空間シャッフル** | **781** | **−128.7°** | **0.19 G** | **0.069°** | **7** | **0.0%** |
| 完全ランダム | 782 | −129.3° | 0.32 G | 0.047° | 8 | 0.0% |
| 全部同位相 | 400 | 21.5° | 0.43 G | 0.004° | 144 | 0.0% |

支持が切れない配り方どうしなら速度は 776〜782 mm/s で一致し、**空間シャッフルは斜め波と同等に走ります**。
しかも「x方向1波長」は同位相の足が1列に並んで線接触になるので、機体がその線まわりに首を振ります
（傾き1.44°、無接地10.8%）。**いちばん波らしい配り方が、いちばん悪い。** ここでは波ではなく当番表です。

**ケースB 卓上（足は地面に固定、150mm角の荷が渡る。下に入るのは3×4足）**

| 位相の配り方 | 結果 |
|---|---|
| 波・x方向 1波長 | 支え続ける（無接地 0.0%、傾き 2.5°） |
| 波・斜め45° 1波長 | 支え続ける（無接地 3.5%、傾き 3.4°） |
| 波・x方向 2波長 | **0.83 秒で転倒** |
| 同じ位相集合を空間シャッフル | **0.22 秒で転倒** |
| 完全ランダム | **0.10 秒で転倒** |
| 3相の市松 | **0.18 秒で転倒** |

**逆になります。** 荷が有限だと、荷の差し渡しに対して波長が十分長い勾配だけが荷を支え続けます。
空間配置が本質です。§1 の寸法制約 `荷 ≪ λ` はここから来ています。

したがって：**「波かどうか」は足の配り方ではなく荷の寸法で決まります。**
荷 ≫ λ なら当番表に、荷 ≪ λ なら波になる。車両の車体は前者の極限です。

> ### 撤回: `bench/wavetest.mjs` の結論
> 以前ここには「位相をシャッフルしても 783 mm/s / 134.7° / 12% と小数点以下まで一致する。
> 位置は一切効いていない。波動ではない」と書いていました。**この試験は無効でした。**
> あのモデルには足の空間座標がなく、機体は質点で、各時刻の力は位相の集合だけの**対称関数**です。
> 並べ替えて一致するのは数式上の恒等式であって、測定ではありません。何も検証していませんでした。
> ファイルは記録として残してありますが、冒頭に無効である旨を書いてあります。
>
> 空間座標を入れて測り直すと、上のとおり**位置は効きます**。ただし効き方が荷の寸法で反転するので、
> 「波動ではない」は車両の場合に限れば結論として生き残りました。卓上では誤りです。

### (b) 歩容でもない。車輪である。しかも車輪より悪い

決定的なのは**どの軸で駆動するか**でした。

| | 駆動軸 | 推力の向き | 上下動 |
|---|---|---|---|
| 車輪 | 円盤自身の法線まわり | 一定 | **不要** |
| この円盤 | 鉛直軸まわり | 1回転で360°回る | **必須** |

円盤を軸に剛結して鉛直まわりに引きずっているので、掃引方向が θ とともに回ります。
だから「向きが合っている間だけ接地させる」ために上下動が要る。
**上下機構は、自分で作り出した問題を自分で塞いでいるだけでした。**

| | 車輪配列 | 傾斜円盤配列 |
|---|---|---|
| 接地率 | 100% | 12% |
| 滑り | ほぼ 0（転がり） | 7〜12% |
| 接地応力 | 基準 | 約8倍 ＋ リムの点接触 |
| 上下機構・位相配り | 不要 | 必須 |

さらに**足のピッチも当初の見積もりの1.5倍**要ります。以前「張り出し 17.6mm → ピッチ 40mm」と
書いていましたが、これは接地している瞬間だけを見た値でした。離地中も円盤は回り続けていて、
円盤面と水平面の交線上にある縁の2点は**傾きに依らず常に水平距離 R** にあります。
つまり掃引体積の外形半径はちょうど `R` で、α・β には依りません。**ピッチ下限は 2R = 60mm** です。
40mm に詰めるなら R=20mm へ落とすことになり、掃引速度が 2/3 になります（`node bench/foot.mjs`）。

### (c) 先行例がある

Disney の HoloTile floor（発明者 Lanny Smoot）が「傾けた円盤を並べ、円盤の方位で搬送方向を決める」もので、
機構レベルで同じです。特許出願 **US 2018/0217662 A1**（優先日 2017-01-30、公開 2018-08-02）に、
傾斜した接触円盤の配列・円盤方位による搬送方向の指定・複数円盤の方位と回転を共通駆動する構成まで
記載されています。

以前「マクロ機械式 × 全方向 × 位相操舵の先行例は見つからなかった」と記録しましたが**誤りでした**。
検索語が波動・進行波に寄っていて当たっていませんでした。しかも HoloTile の「spin and pivot」は
自軸駆動＋操舵、つまり**車輪の正しい使い方**です。

**新規性について**: 傾斜円盤・共通操舵・全方向搬送そのものに新規性を置くのは困難です。
残り得る差分は「ピン軸を β 傾けた1自由度回転から上下動と掃引を同時に生成する具体的機構」ですが、
先行技術とのクレームチャートも実機検証もない現状では、新規性を主張できる段階ではありません。

## いまの立ち位置

**戻るなら案Aです。** ただし当初思っていたより条件が付きます。

- 位相ステップは **Δφ ≥ 60°**（同時接地歯数を 1 未満に保つ）。これで操舵誤差 3.3°、荷速は落ちない
- したがって **λ ≤ 6·ピッチ**、**荷の差し渡しはその 1/3 以下**。ピッチ 50mm なら荷は 100mm 級まで
- **リトラクトは必須**。停止軸を接地したまま残すと荷速が r·ω の 1% まで落ちる
- **車両には使えません。** 車体は λ より大きく、上の不等式を満たせない

`hardware-approximation.md` の卓上向けの結論（リトラクト必須、蛇腹皮膜、Stage 0 での実測）は生きています。
ただし同文書の伝達効率 η は撤回済みです。

## 未検証のまま残っていること

**すべてクーロンモデルの中の話です。** `μ`、パッドの沈み込み `δp`、実際の接地窓は一度も測っていません。

- 操舵誤差は Δφ と δp の比（同時接地歯数）で 1°〜47° まで動きます。**δp を測らないと設計できません**
- 交替周波数の上限は `μ` だけで決まります
- 2つの独立に書いたモデルが同じ卓上について**荷速 21%（`index.html` の局所支持モデル）と
  95%（`bench/compare.mjs` の全面接地モデル）**という食い違った答えを出します。
  差は「荷の下に何本のレールが入るか」で、これも未測定です
- `bench/spatial.mjs` ケースB の絶対値（速度・滑り・ヨー・振動）は刻み幅で ±10% 動きます。
  収束しているのは**転倒するかどうかの判定と転倒時刻（±0.01秒）**までです
