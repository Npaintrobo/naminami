# 離散ピン円環写像の成立領域 — 上界探索と自己反証

対象ベンチ:

```bash
npm run bench:mapping
```

ここでの目的は「成立を証明する」ことではない。連続境界を与えていた `elastic.mjs` から一段戻り、
実際の離散ピン数、円形シート、操舵方向を入れたとき、明らかに成立しない領域を先に落とす。

## モデル

`discrete-map.mjs` は次を解く。

1. 正方格子のピンのうち、円板内にあるピンだけを残す
2. 各ピンへ `w_i = W cos(k d·r_i - q)` を与える
3. ピン間を、曲げエネルギー最小の薄板スプラインで補間する
4. `u_top = -(t/2) grad(w)` から上面の面内写像を測る
5. 操舵角 `0/15/30/45°` の最悪値を取る

`reg=0` はピン変位を完全追従する上界、`reg=1` は追従性を意図的に落とす感度試験である。
`reg` は無次元であり、実材料へ校正するまでは物性値ではない。

## 自己検証

- ピン位置の補間残差: `5.3e-14`
- 正方格子と円板が持つ90°回転対称性の残差: `1.6e-14`
- 評価点刻みを `p/2` から `p/8` へ細分したときの中央値差: `1.1e-3`
- LUの特異ピボット、非有限値は例外終了する

これは実装の内部整合性を確認するものであり、モデルの物理的妥当性を証明するものではない。

## 離散化の結果

12×12ユニットで、操舵角の最悪値を比較した。

| λ/p | 判定 | 理由 |
|---:|---|---|
| 2 | **棄却** | 完全追従でも中央値0.57、5%点0.002、直交漏れ0.38。場所と方向で波が消える |
| 3 | **棄却** | 完全追従でも5%点0.70、直交漏れ0.15。感度条件では中央値0.54 |
| 4 | 境界 | 完全追従ならほぼ通るが、感度条件で中央値0.78・鉛直5%点0.76 |
| 6 | **候補** | 完全追従の5%点0.96、感度条件でも中央値0.95・鉛直5%点0.92 |
| 8 | 写像は良好 | 12×12では円板直径に1.5波長しか入らない。有限円板条件が不足 |

したがって、12×12ピンで「円板内に最低2波長を置く」と「離散写像を安定させる」を同時に満たす
最初の候補は **`λ/p ≈ 6`** となる。

これは一般設計則ではない。薄板スプライン上界モデルから得た、次の詳細解析へ進める探索点である。

## 寸法付き必要条件

`design-window.mjs` は上の写像条件に、次の保守的なスクリーニング条件を重ねる。

| 条件 | 閾値 | 意味 |
|---|---:|---|
| 波面傾斜 `kW` | ≤ 0.25 | 小傾斜近似を大きく外さない |
|表面曲げひずみ `tWk²/2` | ≤ 5% | 線形モデルの使用範囲を制限 |
| 鉛直加速度 `WΩ²/g` | ≤ 0.8 | 無予圧上面の離昇を避ける必要条件 |
| 円板内の波数 `D/λ` | ≥ 2 | 端部だけで結果が決まる領域を除外 |
| 理想写像 | `gain05≥0.90`, `leak95≤0.10` | 完全追従でも悪い案を棄却 |
| 感度写像 | `gain50≥0.85`, `z05≥0.85` | 追従低下ですぐ壊れる案を棄却 |

### 一次試作に向く点

| 項目 | 値 |
|---|---:|
| ピン配列 | 12×12 |
| ピッチ `p` | 25 mm |
| 円板直径 `D` | 300 mm |
| 波長 `λ` | 150 mm (`λ/p=6`) |
| シート厚 `t` | 10 mm |
| 鉛直振幅 `W` | 5 mm |
| 回転数 | 300 rpm |
| 波面傾斜 | 0.209 |
| 曲げひずみ概算 | 4.4% |
| 鉛直加速度 | 0.50 g |
| 無負荷表面速度上界 | 約31 mm/s |

31 mm/sは搬送速度ではない。無荷重上面の面内速度上界であり、荷重、摩擦、溝変形を入れると低下する。

### 現在の例を同じ物差しで見る

`p=50 mm, λ=100 mm, t=6 mm, W=5 mm, 300 rpm` は、

- `λ/p=2`: 離散写像で棄却
- 波面傾斜0.314: 閾値超過
- 曲げひずみ約5.9%: 閾値超過

となる。連続下面を与えたFEMが収束しても、この離散ピン構成の成立根拠にはならない。

## 自己反証レビュー

### 重大: このモデルも実機を証明していない

薄板スプラインは無限平面の曲げエネルギー最小補間であり、有限円板の厳密な自由端条件ではない。
また、ピン位置の鉛直変位を与えており、溝の接触離脱、面圧、局所変形、バックラッシュはない。

### 重大: `reg=1` に物理単位がない

感度試験には使えるが、実ゴムが `reg=0.1` なのか `10` なのかは未測定である。
「λ/p=6なら実機でも成立」とは結論できない。静的な点荷重試験で校正する必要がある。

### 高: 荷重下の面内速度は未検証

上面接触を解いていない。荷重で勾配が潰れる、接触域が移動する、滑りで位相が変わる可能性がある。
このため、表面速度から荷速度への変換係数はまだ0〜1の未知数である。

### 高: 円環溝の半径拘束を入れていない

このモデルは離散鉛直写像を先に検査するためのもの。同心円溝による半径拘束と接線滑りは未実装であり、
回転漏れや操舵トルクを評価できない。`μ_溝 < μ_接地` だけを成立条件にはしない。

### 中: 速度を上げると別の制約が支配する

表面速度はおおむね `tWΩ/λ` に比例するが、鉛直加速度は `WΩ²` に比例する。
したがって回転数を上げ続ける設計は、写像より先に離昇、衝撃、発熱で止まる。

## 次の検証順序

1. **静的写像試験** — 300 mm円板、25 mmピッチ、λ=150 mmで、無荷重の `Gz` と `Gxy` を光学計測
2. **荷重写像試験** — 面圧を段階的に上げ、`Gxy(load)/Gxy(0)` を測る
3. **回転漏れ試験** — 波停止中に操舵だけを往復し、累積ヨーと操舵トルクを測る
4. **低速搬送試験** — 100 rpmから開始し、離昇・滑り・温度を見ながら300 rpmまで上げる
5. **校正後の3D非線形解析** — 実測したゴム物性、ピン剛性、溝摩擦を使う

現時点の研究上の主張は、次までに留める。

> 円形シートと正方格子の離散写像にはサンプリング限界があり、無荷重上界モデルでは
> `λ/p=2` は成立せず、`λ/p≈6` が次段階へ進める最小候補となった。
