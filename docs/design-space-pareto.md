# 円環写像機構の設計領域 — Pareto探索

実行:

```bash
npm run bench:pareto
```

`discrete-mapping-window.md` で得た写像条件を、寸法、速度、曲げひずみ、鉛直加速度、
概算ピン力、円板径、ピン数へ展開した。

## 探索範囲

| 変数 | 探索値 |
|---|---|
| 格子 | 8×8 / 12×12 / 16×16 / 20×20 |
| ピッチ | 12.5〜50 mm |
| `λ/p` | 4 / 6 / 8 / 10 |
| シート厚 | 4〜20 mm |
| 鉛直振幅 | 1〜10 mm |
| 回転数 | 60〜500 rpm |

基本材料は `E=5 MPa, ν=0.49, ρ=1100 kg/m³` とした。これらは測定値ではない。

必要な連続体近似は次のとおり。

```text
無荷重表面速度     v = Gmap · (t/2) · W · (2π/λ) · Ω
表面曲げひずみ     ε = (t/2) · W · (2π/λ)²
鉛直加速度         az = W · Ω²
板の曲げ剛性       B = E t³ / [12(1−ν²)]
正弦波に必要な圧力 q = B (2π/λ)⁴ W
```

ピン力は、上の曲げ圧力、円板へ一様に載る荷重、シート慣性をピッチ面積へ掛けた概算である。
溝の局所面圧やピン本数の時間変化は含まない。

## 設計領域を決める関係

- `λ/p`を増やすほど写像は安定するが、同じ格子数では円板内の波数`D/λ=N/(λ/p)`が減る
- 12×12は`λ/p=6`、16×16は`λ/p=8`、20×20は`λ/p=8〜10`が対応する自然な組合せ
- 速度は`tWΩ/λ`に比例する
- ひずみは`tW/λ²`に比例するため、短波長化は速度より速くひずみを悪化させる
- 鉛直加速度は`WΩ²`に比例するため、回転数だけを上げると離昇が先に支配する
- 厚くして振幅を下げると速度を保ったまま鉛直加速度を下げられるが、ピン力は概ね`t³`で増える

最後の関係により、探索器は「厚め・小振幅・中高速」を選ぶ。ただし薄板モデル自身を守るため
`t/λ≤0.1`を追加した。これを入れない最初の探索では`t=20 mm, λ=120 mm`が上位になったが、
モデル適用外なので自己反証で棄却した。

## 推奨する4領域

### A. 最小構成の原理試作 — 第一選択

| 項目 | 値 |
|---|---:|
| 格子 / 実ピン数 | 12×12 / 112本 |
| `p, λ, D` | 20 / 120 / 240 mm |
| `t, W` | 10 / 2 mm |
| 回転数 | 400 rpm |
| 想定荷重 | 5 kg |
| 無荷重表面速度上界 | 20.7 mm/s |
| 曲げひずみ | 2.7% |
| 鉛直加速度 | 0.36 g |
| 概算ピン力 | 3.7 N/本 |
| 単純化操舵トルク | 0.9 N·m |

最小の112ピンで20 mm/sへ届き、ひずみと加速度に余裕がある。最初に作るならこれを選ぶ。

### B. 20 kg級の均衡点

| 項目 | 値 |
|---|---:|
| 格子 / 実ピン数 | 12×12 / 112本 |
| `p, λ, D` | 25 / 150 / 300 mm |
| `t, W` | 10 / 4 mm |
| 回転数 | 400 rpm |
| 無荷重表面速度上界 | 33.2 mm/s |
| 曲げひずみ | 3.5% |
| 鉛直加速度 | 0.72 g |
| 概算ピン力 | 6.0 N/本 |
| 単純化操舵トルク | 4.1 N·m |

前回の`W=5 mm, 300 rpm`より、小振幅・高速側へ移した。速度上界を保ちながらひずみを
4.4%から3.5%へ下げられる。ただし0.72 gなので、上面接触の動的検証が必要。

### C. 写像剛性が低かった場合の頑健点

| 項目 | 値 |
|---|---:|
| 格子 / 実ピン数 | 20×20 / 316本 |
| `p, λ, D` | 15 / 120 / 300 mm |
| `λ/p` | 8 |
| `t, W` | 10 / 2 mm |
| 回転数 | 400 rpm |
| 無荷重表面速度上界 | 20.9 mm/s |
| 曲げひずみ | 2.7% |
| 鉛直加速度 | 0.36 g |
| 概算ピン力 | 2.0 N/本（5 kg） |

未校正追従係数を`reg=3`まで悪化させ、円板内2.5波長を要求すると12×12と16×16は全滅し、
20×20だけが残る。したがって、実機の点荷重試験で`reg`相当値を測ることが、112ピンで済むか
316ピン必要かを決める最重要試験になる。

### D. 小型高密度点

| 項目 | 値 |
|---|---:|
| 格子 / 実ピン数 | 12×12 / 112本 |
| `p, λ, D` | 12.5 / 75 / 150 mm |
| `t, W` | 6 / 2 mm |
| 回転数 | 500 rpm |
| 無荷重表面速度上界 | 24.9 mm/s |
| 曲げひずみ | 4.2% |
| 鉛直加速度 | 0.56 g |
| 概算ピン力 | 3.6 N/本（20 kg） |

直径150 mmまで縮小できるが、12.5 mmピッチ、500 rpm、短波長による溝加工・摩耗・発熱の
リスクが高い。原理試作より後の小型化候補とする。

## 高性能領域

16×16、`p=15 mm, λ=120 mm, D=240 mm, t=12 mm, W=3 mm, 400 rpm`では、
20 kg条件で表面速度上界38.8 mm/s、ひずみ4.9%、0.54 g、約5.8 N/ピンとなる。

予圧を仮定して加速度1.2 g、ひずみ8%まで許すと60〜80 mm/sの点も出るが、これは現在の
無荷重・薄板モデルでは信頼しない。接触衝撃、ゴム発熱、疲労、溝の引張側強度が支配する。

## 材料・荷重感度

推奨Aでは、`E=2〜10 MPa`、荷重5〜50 kgを振ると概算ピン力は1.8〜10.9 N/本。
推奨Bでは2.2〜12.8 N/本となった。一方、単純化操舵トルクは材料剛性より荷重に支配され、
直径300 mmでは約1.1 N·m（5 kg）から10 N·m（50 kg）まで増える。

したがって鉛直駆動力より、操舵界面の摩擦と固定方法が先に律速になる可能性が高い。

## 自己レビュー

### 重大

- 表面速度は荷速度ではない。荷重下の写像率と摩擦効率は未知
- `reg`は未校正。AとCのどちらが正しい設計領域かはまだ決められない
- 操舵トルクは一様面圧の特殊解で、回転漏れの成立判定には使えない

### 高

- ピン力は連続正弦板の圧力をセル面積へ割り当てた値で、局所面圧・溝端応力を過小評価する
- `E=5 MPa`の線形弾性。ゴムの動的弾性率、損失正接、温度依存性がない
- 疲労寿命を評価していない。400 rpmなら1回転1周期として100万周期は約42時間

### 中

- ピン本数は接点数であり、アクチュエータ数ではない。SAWの共通機械駆動なら複雑性との対応は要精査
- 円板端から1ピッチを評価外にしているため、外周を実接触面として使う場合は過大評価になる

## 決定

最初の実験機はAを基準にする。Aで静的写像率が不足した場合、振幅や回転数を上げず、まず
`λ/p=8`・16×16または20×20へ移る。写像率が確保できてからBへ荷重と速度を上げる。
